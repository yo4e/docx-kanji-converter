# docx-kanji-converter

Word（`.docx`）形式の日本語小説原稿に、定型的な文字変換と書式調整を行うコマンドラインツールです。

> [!CAUTION]
> 現在は試作段階です。変換は文脈を理解せず、本文段落のRun単位で処理します。元ファイルは上書きしませんが、必ず出力結果を確認してください。

## セットアップ

Python 3.10以上を使用します。

```bash
python -m pip install .
```

開発とテストを行う場合：

```bash
python -m pip install -e ".[dev]"
python -m pytest
```

## 使い方

入力ファイルだけを指定すると、同じフォルダに `<元の名前>.converted.docx` を保存します。

```bash
python main.py novel.docx
```

出力先を明示する場合：

```bash
python main.py novel.docx checked.docx
```

インストール後はコマンド名でも実行できます。

```bash
docx-kanji-converter novel.docx checked.docx
```

### dry-run

ファイルを書き出さず、適用される変更操作の件数を表示します。

```bash
python main.py novel.docx --dry-run
```

### 変換ルールを無効にする

`--disable` は複数回指定できます。

```bash
python main.py novel.docx --disable numbers --disable font
```

指定できるルール：

| ルール | 内容 |
| --- | --- |
| `indent` | 本文段落の先頭へ全角スペースを追加 |
| `numbers` | 1〜4桁の半角数字を漢数字化 |
| `ellipsis` | `...` を `……` へ置換 |
| `ascii` | 半角英字を全角英字化 |
| `punctuation` | `！` / `？` 後へ全角スペースを追加 |
| `italic` | 斜体を解除して太字化 |
| `font` | フォント名をリセットし、本文を12pt化 |

### 既存ファイルの置換

出力先が既に存在する場合は停止します。明示的に置き換える場合だけ `--force` を指定します。

```bash
python main.py novel.docx checked.docx --force
```

入力ファイル自身を出力先に指定することはできません。

## 現在の処理内容

### 1. 本文段落の字下げ

次のいずれにも該当しない段落では、最初のRunの先頭に全角スペースを1字追加します。

- 段落スタイル名が `見出し` または `Heading` で始まる
- 段落本文が既に全角スペースで始まる
- 段落本文が `「`、`（`、`『` のいずれかで始まる
- 空段落または空白だけの段落

同じ文書に複数回適用しても、字下げを重ねません。

### 2. 半角数字の漢数字化

1〜4桁の連続する半角数字（`0-9`）を漢数字へ変換します。

- `0` → `零`
- `11` → `十一`
- `22` → `二十二`
- `100` → `百`

5桁以上の数字は誤変換とクラッシュを避けるため変更せず、レポートの `numbers_over_4_digits` に記録します。

### 3. 三点リーダーの置換

半角ピリオド3文字の `...` を `……` に置換します。Unicodeの `…` 単体や、複数のRunに分かれた `...` は対象外です。

### 4. 半角英字の全角化

半角の英字 `A-Z` と `a-z` を対応する全角英字へ変換します。数字、記号、空白はこのルールでは変換しません。

### 5. 感嘆符・疑問符後の空白挿入

`！` または `？` の直後に全角スペースを追加します。ただし、直後が全角スペース、`）`、`」`、`』` の場合は追加しません。

### 6. 斜体を太字へ変更

Runが明示的に斜体の場合、斜体を解除して太字に変更します。

### 7. フォント設定の調整

すべてのRunで `run.font.name` をリセットし、見出し以外のRunを12ptに設定します。

## 処理対象の範囲

現在処理するのは、`python-docx` の `doc.paragraphs` から取得できる通常の本文段落です。

次の要素は未検証、または処理対象外です。

- 表内の段落
- ヘッダーとフッター
- 脚注と文末脚注
- テキストボックス
- コメント
- ルビ、傍点などWord固有の高度な構造
- 埋め込みオブジェクト

## 既知の制約と危険箇所

- 数字と英字は文脈に関係なく変換する
- 4桁以下の日付、時刻、型番、URL、メールアドレス、単位付き数値も変換対象になりうる
- Run境界をまたぐ文字列は検出できない
- 見出し判定は段落スタイル名に依存する
- `font` は本文の意図したサイズ差を失わせる可能性がある
- `italic` は意味上必要な斜体も失わせる可能性がある
- dry-runは変更件数を示すが、文脈上の妥当性までは判定しない

危険性の高いルールは `--disable numbers`、`--disable italic`、`--disable font` のように無効化できます。
